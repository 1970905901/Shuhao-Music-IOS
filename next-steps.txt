[x] A1. Song 缺少 platform 字段
    文件：Models/Song.swift、ViewModels/PlayerViewModel.swift、Services/KugouMusicService.swift、
         Services/KuwoMusicService.swift、Services/NetEaseMusicService.swift、Services/MusicServiceFactory.swift
    说明：已为 Song 增加 platform 字段并参与 Codable（旧历史/收藏数据缺该字段时默认 .qq）；
         播放链接与歌词改为按 song.platform 选取自定义音源 sourceCode 与歌词 service，
         不再受"当前选中平台"影响；各平台 Service 构造 Song 时显式传入自身平台。
    兼容说明：升级前持久化的历史/收藏没有 platform，会按 QQ 音乐处理，属已知限制。

[x] A2. 非 QQ 平台封面走了 QQ 封面模板
    文件：Models/Song.swift（init(from:)）
    说明：coverURL 改为仅 platform == .qq 时拼接 QQ 封面，其它平台一律 nil 走播放器占位图。

[x] A3. 未导入自定义音源时静默失败、无引导
    文件：ViewModels/PlayerViewModel.swift、Services/CustomSourceService.swift
    说明：本项目约定播放链接只来自自定义音源，QQMusicAPIService.audioURL(for:) 保留但明确不启用；
         新增 CustomSourceService.hasSource() 前置校验，无音源时抛出明确文案
         "未导入自定义音源，请前往「自定义音源」导入 LxMusic JS 源后再播放"。

[x] A0. Info.plist 缺少 ATS 配置，http 接口被系统拦截（阻断级）
    文件：Shuhao-Music-IOS/ShuhaoMusic/Info.plist、QQMusicClient/Resources/Info.plist
    说明：酷我全部接口、酷狗歌单/排行榜接口均为 http://，未配置 NSAppTransportSecurity 时
         iOS 会直接拦截请求，导致这些平台在真机上完全不可用；
         已补 NSAllowsArbitraryLoads（与参考项目 LX-Y Music 一致）。
         后续可收敛为 NSExceptionDomains 白名单以降低审核风险。

[x] A4. 网易云缺失 4 项能力且 UI 无降级（降级已完成，接口待 weapi 加密）
    文件：Models/MusicPlatform.swift、Views/EmptyStateView.swift（新增）、各详情页 ViewModel 与 View、
         Views/SearchView.swift
    说明：新增 PlatformCapability 能力声明与各平台 capabilities；
         ViewModel 请求前先校验能力，不支持时展示 EmptyStateView；
         SongRow 的"查看专辑/查看歌手"入口按能力显隐（A9 一并解决）。
         网易云接口本身需 weapi 加密（见 A13），目前仍只支持搜索与歌词。

[x] A5. 酷我歌单广场缺失、酷狗歌单接口已失效
    文件：Services/KuwoMusicService.swift、Services/KugouMusicService.swift
    说明：接口均已在真机网络下逐条实测：
         - 酷我歌单广场：wapi.kuwo.cn/api/pc/classify/playlist/getRcmPlayList（原为 return []）
         - 酷我歌单详情：nplserver.kuwo.cn/pl.svc 原参数返回空 musiclist，改用 keyset=pl2012 等参数
         - 酷狗歌单广场：mobilecdn.kugou.com/api/v3/playlist/list 已返回 Access Deny，
           改用 www2.kugou.kugou.com/yueku/v9/special/getSpecial
         - 酷狗歌单详情：mobilecdn .../playlist/songs 同样 Access Deny，
           改为解析官网页面内嵌的 global.data
         歌单名不再写死"歌单"（酷狗从页面提取，酷我取 title）（A8 一并解决）。

[ ] A13. 实现网易云 weapi 加密，解锁歌单 / 专辑 / 歌手 / 排行榜详情
    文件：Services/NetEaseMusicService.swift（需新增加密辅助类）
    说明：实测网易云公开老接口已全面风控：/api/playlist/detail 返回 20001、
         /api/playlist/list 返回 500、/api/album/{id} 返回 -462、/api/artists 返回 404；
         必须移植 weapi 加密（AES-128-CBC + RSA）才能接入。可参考 wy/utils/crypto.js。

[ ] A14. 实现酷我 wbd 加密，解锁排行榜详情
    文件：Services/KuwoMusicService.swift（需新增加密辅助类）
    说明：酷我排行榜详情接口 https://wbd.kuwo.cn/api/bd/bang/bang_info 需要 wbdCrypto，
         参考项目见 kw/util.js。

[ ] A15. 酷我歌曲 ID 与自定义音源对齐
    文件：Services/KuwoMusicService.swift
    说明：LX 的 kw 音源使用纯数字 id（MUSICRID 去掉 MUSIC_ 前缀），
         本项目此前使用 MUSIC_xxx 作为 mid，可能导致部分按 LX 约定实现的音源无法匹配；
         已改为搜索 / 歌单详情均输出纯数字 id。升级前历史/收藏中的 MUSIC_ 格式歌曲播放可能受影响。

[ ] A16. 非 QQ 平台歌曲封面在持久化后丢失
    文件：Models/Song.swift
    说明：当前 Song 的 Codable 未编码 coverURL，跨平台歌曲的封面在收藏/历史持久化后会变为 nil；
         如希望收藏列表显示封面，需把 coverURL 加入 CodingKeys 并在 decode 时按 platform 还原。
